# 水軍與長江／黃河移動（設計備忘）

> 狀態：**規劃中**，尚未接入移動（`AbstractTerrain.CalculateMovement`）／尋路。地形已有 `ShipRequirement` 欄位。  
> 陸地：地形 tier **0 / 8 / 12 / 16**，日行動池 = 兵種 **`mobility`**（見前文討論）。

---

## 為什麼要這樣設計：三國志14 的問題與本專案解法

### 14 的結構性問題

| 現象 | 後果 |
|------|------|
| 部隊**一下水就變鬥艦**（或頂級水軍形態） | 水陸兩用過強，無專職分工 |
| **到處上岸**、繞後包圍 | 防守方無「險」可守，江防線形同虛設 |
| 東吲地理優勢難體現 | 長江天險變成「誰都能無腦渡江」 |

結果：**東吲無險可守**——不是江不寬，是規則讓大軍可以任意水格↔岸格切換。

### 本專案對策（核心）

```text
取得大船（蒙衝及以上）→ 只能在「港灣」下水時
任何船都可任意靠岸     → 但非港灣上岸，船即丟棄
船非常貴               → 隨便上岸 = 白白燒錢
```

不是「禁止」大船任意上岸，而是**讓任意上岸付出昂貴代價**。由此產生 **14 缺少的戰役節奏**：

| 層級 | 玩法 |
|------|------|
| **戰略** | 要過江又想保住船隊？先奪或壓制 **港灣**（襄陽、江陵、武昌、建业…），港→港渡江船才留得住 |
| **牽制** | 進攻方 **派兵壓制港灣**、吸引／釘住對方 **主力**；不壓港就得在任意岸上陸、整支船隊報廢 |
| **戰術破局** | 走舸（預設、丟了無損失）在港灣戰場側翼 **靠岸**，做 **陸上突破**（小股、騷擾、燒糧）；大船任意上岸是「不惜血本」的選擇 |

> **架構修訂**：全遊戲已**取消補給線切斷斷糧**；上表「斷道、燒糧」指戰術騷擾與兵團自帶糧耗，見 [`COMBAT_AND_CAMPAIGN_ARCHITECTURE.md`](COMBAT_AND_CAMPAIGN_ARCHITECTURE.md)。

東吲「有險可守」= **港灣鏈 + 激流 + 寬江 + 船貴**：東吳握有港灣，船能反覆使用；曹魏強渡若不攻港，每次登陸都在燒船。水軍優勢 = **經濟優勢**，而不是規則禁止對手上岸。

### 與兵種線的對應

| 單位 | 角色（呼應上文） |
|------|------------------|
| 走舸 | 所有部隊預設的船；側翼登陸、偵查、接舷；丟棄無損失 |
| 蒙衝+ | 江面主力、過激流；只能從港灣取得；非港灣上岸即報廢 |
| 樓船／鬥艦 | 火力與攻城平台；最貴，任意上岸的代價最大 |

**設計底線**：部隊**不會**因進入水格就自動變成鬥艦；下水時用的是部隊身上「實際帶著的船」，且遵守上表規則。

## 部隊陸／水兩套兵裝

> 取代舊稿「水軍編制與陸軍編制分離」。狀態：**設計定案，尚未實作**。

### 規則

| 項目 | 決策 |
|------|------|
| 適用對象 | **所有部隊**：戰鬥部隊、兵團、運輸隊 |
| 兩套兵裝 | 每支部隊同時有 **陸上兵裝** 與 **水上兵裝（船）**；例：大戟士部隊在陸上是大戟士，一進大河就是走舸 |
| 一定有船 | 水上兵裝**不可為空**；預設 **走舸** `navy.small` |
| 何時算「在水上」 | 腳下地形 `ShipRequirement >= 0`（大河、急流、沿海…）；河流（-1）仍用陸上兵裝（涉水） |
| 升級船隻 | 只有**經由港口入水**時，才可改帶 **走舸以上**（蒙衝、樓船、鬥艦）|
| 靠岸 | **所有船都可任意靠岸**，不限走舸 |
| 非港口上岸 | 部隊一踏上陸地，船**自動丟棄**，水上兵裝回到預設走舸 |
| 港口上岸 | 船**保留**，下次下水仍是同一艘 |
| 船價 | 船設計得**非常貴**；任意上岸丟船就是代價 |

### 兵團與運輸隊

| 項目 | 決策 |
|------|------|
| 陸上 | 沿用現行（無兵種，機動由設定檔依部隊類型決定） |
| 水上 | 同樣預設走舸 |
| 港口加掛運輸船 | 經由港口入水時可**增加運輸船隻**（載運量↑），代價是**速度變慢** |

### 與既有規則的關係

- 舊稿「蒙衝以上渡江必須港→港」**不再是硬性限制**：大船隨時能任意上岸，只是船會報廢；想保住船就得港→港。
- 走舸是預設船，丟了沒有損失，所以走舸隊任意上岸最划算。
- 船級門檻：地形 `ShipRequirement`（0 走舸、1 蒙衝、2 樓船）對照部隊目前的船級；船級來自既有兵種線 `navy.small → medium → large → final`（0～3）。

### 待決定

- **「港口」怎麼判定**：地形「城寨」同時涵蓋港灣、陣、寨、縣城，不能只看地形；建議由 Location 上的建築（港灣）判定。
- 戰鬥部隊的兵種數值目前在 `BindTroopKind` 時**複製**進部隊欄位；改成兩套兵裝後，應改為依「目前兵裝」即時讀取。
- 武將兵科適性：水上時是否改看水軍適性。
- 運輸船的載運量與減速幅度。

## 水上移動：每格扣 4 行動力

| 項目 | 決策 |
|------|------|
| 消耗 | 水軍在**一般水格**上，**每進 1 格扣 4 點行動力**（不是「每天固定扣 4」） |
| 對比陸地 | tier-1 **8**、tier-2 **12**、tier-3 **16** |

### 渡江節奏（為何不拖大行軍）

寬江常 **約 10～20 格**（100～200 km 帶狀水域），橫渡約 **5～10 格**直線水路：

| 橫渡水路格數 | 僅水路消耗（×4） | 約天數（走舸 mobility 24） |
|--------------|------------------|----------------------------|
| 6 格 | 24 | **~1 天**（滿池剛好） |
| 12 格 | 48 | **~2 天** |
| 15～20 格 | 60～80 | **~3～4 天** |

若主力是 **蒙衝 mobility 20**：同樣 12 格約 **3 天**。  
加上**激流繞行、水戰、港灣進出、陆军集结**，整體 **橫渡寬江約 3～5 個遊戲日** → 比純陸軍長途奔襲慢，但**不會卡死節奏**，也留給東吳反應時間。

## 激流（Rapids）

| 項目 | 決策 |
|------|------|
| 地形 | 水上格可標 **激流** |
| 走舸 `navy.small` | **不可過**激流 |
| 蒙衝 `navy.medium` 及以上 | 需 **研發科技** 後方可過激流 |
| 流向 | **不模擬**順逆流 |

走舸：**最快**，但被激流限制走位；蒙衝是科技 + 兵種分水嶺。

## 港灣與靠岸（提高港灣價值）

### 核心規則

| 行為 | 走舸 `navy.small` | 蒙衝及以上 |
|------|-------------------|------------|
| **取得** | 所有部隊預設就有 | 只能在 **港灣** 下水時換上 |
| **在江上行走** | 水格每格 **-4** | 同左 |
| **靠岸 / 登陸** | **任意靠岸**；非港灣上岸船丟棄（無損失，下次仍有走舸） | **任意靠岸**；非港灣上岸船**丟棄**（昂貴損失）；港灣上岸則保留 |

### 設計意圖（一句話）

- **走舸** = 輕便、免費：偷渡、偵查、小隊登陸、接舷——**繞過港灣**（對應「走舸旁邊上岸做陸上突破」）。  
- **蒙衝以上 / 大船隊** = 主力與物資，而且很貴：**港灣是保住船隊的咽喉**；進攻方 **壓制港灣、牽制主力** 後港→港渡江，船才能留下來繼續用。  
- 蒙衝、樓船、鬥艦 **平時在江上不用每回合回港灣泊船**；與走舸差在 **取得方式、價格** 與 **激流**，不是差在「能不能在江上待著」或「能不能上岸」。

### 典型攻防腳本（備忘）

**北岸攻東吲（如曹魏）**

1. 主力東向壓 **武昌／江陵港灣**，逼東吲水軍決戰或分兵。  
2. 奪港後以蒙衝以上船隊港→港投送大軍（3～5 日水路節奏），船隊保留；不奪港硬上任意岸則整支船隊報廢。  
3. **走舸** 自港戰側翼任意靠岸：斷補給、占高地、配合主力合擊——**不能**单靠走舸把全城围死。

**東吲防守**

1. 守 **港灣 + 激流** 節點，遲滯大船隊。  
2. 走舸反制走舸，蒙衝對蒙衝；握有港灣＝船能反覆使用，對手每次任意上岸都在燒船。  
3. 江寬 + 水格 -4：南北增援仍比純陸路快，體現 **天險在我**。

### 陸軍（備忘）

- 每支部隊都自帶走舸（見「部隊陸／水兩套兵裝」），下水即以走舸行動。  
- 渡江方式：  
  - **走舸**（任意岸上下，免費）；或  
  - **港灣取得蒙衝及以上**橫江：港→港保住船，任意岸上陸則船報廢。

### 地圖要素（待做）

| 地形 / 建築 | 用途 |
|-------------|------|
| **港灣** | 換上大船、上岸保留船隻、卸載、貿易、造船（可擴） |
| **渡口**（可選） | 與港灣不同：輕渡／棧道；不提供大船、上岸不保留船 |
| **任意岸格** | 所有船都可登陸，但船丟棄 |

## 水軍兵種線

```text
走舸 [navy.small] → 蒙衝 [navy.medium] → 樓船 [navy.large] → 鬥艦 [navy.final]
```

| 階段 | 規劃角色 |
|------|----------|
| 走舸 | 預設、免費；最快（水格 -4）；**不過激流** |
| 蒙衝 | 港灣取得、昂貴；激流（+科技）；江面主力 |
| 樓船 / 鬥艦 | 港灣取得、最貴；火力、攻城；江上不需每日回港 |

所有船都可任意靠岸；非港灣上岸即丟棄。

數值見 `Assets/StreamingAssets/chinese/unit.properties`。
